# Terms of Use

This file describes the default use boundary for Janus Wordscape OS. It is not
legal advice.

## 1. Product Scope

Janus Wordscape OS is a local-first vocabulary learning runtime. It helps users
import prepared word-card packages, run FSRS-based review, browse relationship
graphs, and export local backups.

The project does not provide legal, medical, financial, or professional advice.
Learning results depend on user input, card quality, browser storage, and actual
review behavior.

## 2. Local Data Responsibility

By default, learning data is stored in the user's browser IndexedDB.

Users are responsible for:

- exporting backups before clearing browser data, changing devices, or changing
  domains;
- storing backup files safely;
- verifying imported card packages before use;
- understanding that different domains have different browser storage.

## 4. Community Content

Community card packages are user-created content. They are treated as untrusted
input and are not automatically endorsed by Janus Wordscape OS.

Users who import community packages should check:

- package source and author;
- package license;
- whether commercial reuse is allowed;
- whether third-party dictionary, audio, images, or copyrighted text are
  included;
- whether the package passes schema and security validation.
